# えごさ拡張（Chrome拡張）

開いている英語ページに、えごさの読み方を重ねるChrome拡張です。

Webアプリ版のえごさは、記事のURLから本文を取り込んで表示します。ところが、サイトによってはCAPTCHA（画像認証）やログインが必要で、本文を取り込めないことがあります。この拡張は、そういうページのための予備の動線です。自分で開けるページなら、そのページの上でそのまま読めます。

## できること

- ページ右下の「えごさ」ボタンを押すと、ページの文がタップできるようになります
- 単語をタップすると、画面下のバーに日本語訳が出ます
- 句やイディオム（点線の下線）は、ひとかたまりで意味が出ます
- 文の単語でない所をタップすると、文全体の訳が出ます
- 「ふりがなに貯める」を押した単語や句は、拡張の中に保存され、次からはルビ付きで表示されます

訳の取得には MyMemory の無料翻訳を使っています。

## 入れ方

Chromeのストアには出していないので、開発者向けの方法で入れます。

1. このリポジトリの `extension` フォルダを、自分のPCにダウンロードします
2. Chromeで `chrome://extensions` を開きます
3. 右上の「デベロッパーモード」をオンにします
4. 「パッケージ化されていない拡張機能を読み込む」を押して、`extension` フォルダを選びます
5. 英語のページを開いて、右下に出る「えごさ」ボタンを押します

## 注意

- 使えるのはPCのChromeだけです。iPhoneのブラウザでは拡張機能が動かないため、スマホではWebアプリ版の「テキストを貼って読む」を使ってください
- ページの作りによっては、うまく重ねられないことがあります。その場合も、貼って読む方法は使えます
